HOW TO ADD PLANT PHOTOS
========================

1. Put your plant photos in this folder: public/plant-photos/

2. Name each photo exactly like this (lowercase, hyphens, .jpg):
   neem.jpg
   mango.jpg
   banyan.jpg
   peepal.jpg
   gulmohar.jpg
   curry-leaf.jpg
   ashoka.jpg
   jackfruit.jpg
   tamarind.jpg
   coconut.jpg
   aloe-vera.jpg
   spider-plant.jpg
   peace-lily.jpg
   monstera.jpg
   snake-plant.jpg
   pothos.jpg
   rubber-plant.jpg
   zz-plant.jpg
   tulsi.jpg
   ginger.jpg
   ashwagandha.jpg
   giloy.jpg
   lemon-grass.jpg
   brahmi.jpg
   moringa.jpg
   rose.jpg
   orchid.jpg
   sunflower.jpg
   marigold.jpg
   bougainvillea.jpg
   hero-banner.jpg       ← Homepage background photo
   chatbot-mascot.jpg    ← Chatbot button image

3. If a photo is missing, the website automatically shows the emoji instead.
   No code changes needed — just add the file!

4. In VS Code: Right-click the plant-photos folder → "Reveal in File Explorer"
   Then paste your photos there.

5. Any image format works (JPG recommended for smaller file size).
